# 真实数据回测报告（Real-Data Backtest Report）

> **数据声明**：本报告使用的行情为**公开来源、后复权(hfq) A 股日线**，仅用于**研究与教学演示**，不保证准确/完整/及时，**不构成任何投资建议**。回测为历史模拟，未考虑全部真实约束，实盘结果可能显著不同。

## 一、数据与口径

- 数据目录：`/home/zhuoming.wang/quant-hub/kairos/kairos-data/data/ashare`
- 标的数量：**38** 只（成分取自文件名，如 `sh600519`）
- 回测区间：**2018-10-16 ~ 2026-09-24**，共 **1931** 个交易日（约 7.66 年）
- 清洗口径（`load_close_panel`，同系列可比）：**非正价 → NaN → 前向填充 ffill → 按全体上市日裁剪到公共有效区间**。数据为后复权(hfq)，价格恒正、收益率正确；非正价防御性处理用于停牌等异常，裁剪保证面板无缺口、无前视。
- 成本模型：佣金 3.0bp（最低 5 元） + 滑点 5bp。年化基准 252 交易日。

## 二、向量化回测：横截面动量 Top-K

- **策略**：每 21 个交易日，按过去 126 日涨幅选出最强的 5 只等权持有，其余空仓；信号只用截至当期数据，`VectorBacktester` 内部再滞后一期（上一期权重 × 本期收益）。
- **基准**：全成分**等权买入持有**（期初等额买入并持有，权重随行情漂移，被动无成本）。
- 净值口径起点均为 1.0，策略为**扣成本后**净值。

| 指标 | 策略 | 基准(买入持有) |
|---|---|---|
| 累计收益 | 106.37% | 143.30% |
| 年化收益 CAGR | 9.92% | 12.30% |
| 年化波动 | 26.30% | 20.94% |
| 夏普比率 | 0.49 | 0.66 |
| 索提诺比率 | 0.72 | 0.97 |
| 最大回撤 | 55.22% | 44.92% |
| 卡玛比率 | 0.18 | 0.27 |
| 胜率 | 49.36% | 50.36% |
| 年化换手(双边) | 11.21x | ≈0（持有不动） |

- 累计换手 **85.9x**（双边），成本拖累约 **6.87%**（毛→净）。

**诚实结论（向量化）**：在该成分（多为事后已知的大市值、高流动性龙头）与区间内，等权买入持有本身非常强势（累计 143.30%、夏普 0.66）。动量策略累计收益 106.37%（低于基准约 36.9 个百分点），夏普 0.49（基准 0.66）；最大回撤由 44.92% 升至 55.22%（相差约 10.3 个百分点）。换言之，简单横截面动量在此未能跑赢强势的等权基准，且**回撤反而更深**，代价是更高的换手与成本。该结论对回看窗口/持仓数/调仓频率**较敏感**，且基准受成分**幸存者/选择偏差**美化，不应据此外推为可实盘复制的超额收益。

## 三、事件驱动回测：双均线择时

- **策略**：单标的 `sh600519` 的 20/60 双均线择时（短均线上穿长均线满仓、下穿清仓，只做多/持币）。逐 bar 推进，订单在**下一 bar** 含滑点与佣金成交，无杠杆、买入受现金约束。
- **基准**：同一标的的**买入持有**（经同一引擎、同一成本模型撮合）。
- 初始资金 1,000,000 元；下表净值为归一化后（起点=1.0）。

| 指标 | 策略 | 基准(买入持有) |
|---|---|---|
| 累计收益 | 95.29% | 118.32% |
| 年化收益 CAGR | 9.13% | 10.73% |
| 年化波动 | 18.04% | 26.43% |
| 夏普比率 | 0.57 | 0.52 |
| 索提诺比率 | 0.87 | 0.78 |
| 最大回撤 | 42.38% | 45.15% |
| 卡玛比率 | 0.22 | 0.24 |
| 成交笔数 | 40 | 1 |
| 累计佣金(元) | 26,377 | 300 |
| 年化换手(单边) | 5.21x | 0.06x |

**诚实结论（事件驱动）**：双均线择时把最大回撤由 45.15% 降至 42.38%（相差约 2.8 个百分点），夏普 0.57（基准 0.52，差 +0.06），索提诺 0.87（基准 0.78）；累计收益 95.29% 低于买入持有的 118.32%（相差约 23.0 个百分点）——趋势跟踪在单边行情中常因**频繁进出、踏空反弹**而让渡部分涨幅，以换取更平滑的净值与更低的回撤。**单标的择时高度依赖标的与参数**，此处仅为演示引擎在真实数据上的正确性与风险/收益取舍，并非推荐信号。

## 四、防未来函数

- 向量化：信号仅用截至 t 的历史收益；`VectorBacktester` 用「上一期权重 × 本期收益」，杜绝前视。
- 事件驱动：`on_bar(i)` 仅能取到截至第 i 根 bar 的历史；订单于第 i+1 根 bar 成交。
- 数据清洗：ffill 只用历史价；裁剪仅依据各标的自身有效区间，均不引入未来信息。

## 六、局限与风险

- **幸存者/选择偏差**：成分为事后挑选的知名龙头，等权买入持有基准被系统性美化。
- **参数敏感**：动量与双均线的表现对窗口/持仓数/调仓频率敏感，本报告用先验常用参数，未做样本内择优。
- **成本与冲击**：仅建模佣金+固定滑点，未含涨跌停、停牌、冲击成本、税费与借券约束。
- **前复权口径**：以数据源为准，可能存在偏差；早期负价已按无效处理。
- **单标的择时**：事件驱动示例为单标的，结论不具横截面代表性。

> 再次声明：以上均为历史数据的**研究性模拟**，**不构成投资建议**。
